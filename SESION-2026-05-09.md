## Decisiones de UX importantes

1. **Hero minimalista, info abajo:** se intentó primero meter una tarjeta
   con la reseña dentro del hero, pero competía visualmente con el avatar
   y el CTA. Decisión: hero queda limpio (avatar + título + CTA + chips
   pequeños), reseña en sección below-the-fold.

2. **Chips con flecha "›":** sin la flecha, los chips se veían como
   etiquetas decorativas. Con la flecha + label "Toca un tema..." quedan
   obvios como botones interactivos.

3. **Modal NO desplegable por sección:** se consideró hacer las secciones
   del modal (incluye / ejemplos / no cubre) colapsables. Decisión: dejarlas
   abiertas todas porque el contenido es corto y desplegar agrega fricción.

4. **Tipografía:** chat sube de 14 → 17px porque feedback de usuarios
   reales decía que se veía chico. Headings dentro de respuestas también.

5. **Errores de mic:** al fallar, no mostrar el error técnico de OpenAI
   sino un mensaje amigable. El error real queda en logs del backend.
